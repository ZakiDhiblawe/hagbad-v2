# Hagbad System

A group-based savings platform (Ayuuto / ROSCA system).

## Project Structure


hagbad-v2/
├── backend/ # FastAPI backend (API + database)
└── frontend/ # HTML/CSS/JS frontend


## How It Works

- Backend provides APIs (FastAPI + PostgreSQL)
- Frontend consumes APIs (fetch)

## Modules (Planned)

- Users (Auth)
- Groups
- Group Members
- Cycles
- Payments
- Payouts
